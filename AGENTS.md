# AGENTS.md

## Project
Lesson scheduling web app for a private tutoring school. Specs and plans live in `planning/`:
- `planning/spec iz intervjua.md` – product spec, assumptions, open risks
- `planning/implementation-plan.md` – phased implementation plan

## Language rules
- The user interface (all visible text) is in Serbian, Latin script.
- Code, identifiers, comments, commit messages and technical documentation are in English.

## Workflow rules
- Test every phase before moving on to the next one. A phase is done only when its "Gotovo kad" (done when) criteria in `planning/implementation-plan.md` are met and the relevant tests pass.
